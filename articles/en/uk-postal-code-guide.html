UK Postal Code System Guide: Address Format Rules & Writing Tips

📅 August 2026 · 🏷️ UK Postal Code · British Address · Postcode System

The United Kingdom operates one of the world's most sophisticated postal code systems. Unlike the numeric ZIP codes used in the US, UK postcodes combine letters and numbers to pinpoint locations with remarkable precision — sometimes down to a single building. Understanding this system is essential for ecommerce shipping, international mail, and online form filling.

1. UK Postcode Formats: Six Common Patterns

UK postcodes are alphanumeric and always follow the general structure of an Outward Code (identifying the postal area and district) and an Inward Code (identifying the sector and unit). There are six recognized formats, depending on the region:

AN NAAM1 1AAManchester city centre
ANN NAAB15 1AABirmingham Edgbaston

ANA NAAW1A 1AACentral London (BBC)
AANA NAAEC2A 1AAEast Central London
💡 Key Rule: The Outward Code always contains 2–4 characters, and the Inward Code is always 3 characters (one digit followed by two letters). The total length is always between 5 and 7 characters, including the space.

3. Standard UK Address Format

Royal Mail, the UK's postal service, recommends a specific address layout. Unlike the US three-line format, UK addresses are typically written across multiple lines with specific ordering rules:

Line-by-Line Breakdown

  1. Addressee's Name — Full name of the recipient or company name.
  2. Premise / Building Name or Number — House number and street name (e.g., "42 High Street"). If the property has a name rather than a number, that comes first (e.g., "Rose Cottage, Church Lane").
  3. Locality — Optional line for village, neighborhood, or dependent locality.
  4. Post Town — The postal town, printed in BLOCK CAPITALS (e.g., "LONDON", "MANCHESTER").
  5. Postcode — Printed in BLOCK CAPITALS on the last line, separated from the post town by a single space.
Example:
Mr John Smith
42 High Street
Wimbledon
LONDON
SW19 5AB
💡 Important: Royal Mail does not require the county name on envelopes. The post town and postcode together are sufficient for delivery. Including a county can actually slow down automated sorting.

4. UK vs US Address Format: Key Differences

Many international senders mistakenly apply US address conventions to UK addresses. Here are the critical differences you need to know:

City PositioningPost town on its own line, BLOCK CAPITALSCity, State abbreviation, ZIP on one line

The most common mistake is writing a UK address in the US "City, State ZIP" format. UK addresses do not use commas between the post town and postcode, and there is no state or province equivalent.

5. Common Mistakes When Writing UK Addresses

Even experienced shippers make these errors when formatting UK addresses. Avoid them to prevent delivery delays or returned parcels:

Mistake 1: Using Commas

Royal Mail's automated sorting systems are optimized for comma-free addresses. Do not add commas at the end of each line. The post town and postcode should appear on separate lines without punctuation.

Mistake 2: Missing the Space in the Postcode

The space between the Outward and Inward Code is required. Writing "SW1A1AA" instead of "SW1A 1AA" will cause validation failures on many websites and shipping platforms.

Mistake 3: Including the County

Royal Mail phased out the requirement for county names in 1996. Including a county like "Surrey" or "Kent" can confuse automated sorting equipment. Omit it unless the address is in a rural area where it helps disambiguate the location.

Mistake 4: Confusing "London" Post Towns

Not every address in Greater London uses "LONDON" as the post town. Some outer London districts use their own post towns (e.g., "CROYDON", "ROMFORD", "ILFORD"). Always use the post town that matches the postcode.

Mistake 5: Using US State Abbreviations

Some forms designed for US addresses will force you to select a "state." For UK addresses, this is not applicable. If a form requires a state selection, treat it as a system limitation, not an address requirement.

6. Special Address Types in the UK

PO Box Addresses

UK PO Box addresses are straightforward: "PO Box" followed by the box number, then the post town and postcode. For example:

PO Box 1234
LONDON
WC1A 1AA

British Forces Post Office (BFPO)

BFPO addresses serve UK military personnel stationed abroad. They use a unique numbering system (e.g., "BFPO 123") and are routed through a central hub in London regardless of the actual destination country.

Flat and Apartment Addresses

In the UK, flat numbers are placed before the building number, not after. For example:

Flat 3, 24 Baker Street
LONDON
NW1 5RT

This is the opposite of the US convention ("24 Baker Street, Apt 3"), so pay close attention to this ordering when formatting UK addresses.
